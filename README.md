# I-5 Load Planner (unofficial demo)

This is an unofficial browser demo of a trailer load planner.

- The crates, pallets, and weights are made up.
- It is not a production tool. Out of the box it isn't connected to any job or customer data.
- Optional **Shipment Log** panel: it only works after the owner deploys a private Google Apps Script web app and clicks *Connect* in their own browser. The web app URL and key are kept in that browser's localStorage. No sheet IDs, keys, or shipment data are stored in this repository.
- GitHub Pages is meant to serve `index.html` from the repository root on the `main` branch.
