# I-5 Load Planner (unofficial demo)

This is an unofficial browser demo of a trailer load planner.

- The crates, pallets, and weights are made up.
- It is not a production tool. The demo crates aren't job or customer data.
- **Shipment Log** panel: it talks to I-5 Design Build's Google Apps Script web app, whose URL is built in as the default. That web app only accepts people signed in to an I-5 Design Build Google account, so for anyone else the panel just shows an error. No sheet IDs, keys, or shipment data are stored in this repository.
- GitHub Pages is meant to serve `index.html` from the repository root on the `main` branch.
